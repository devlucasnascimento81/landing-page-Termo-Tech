## 📖 Sobre o projeto

**Termo Tech** é uma landing page desenvolvida para divulgar os serviços de uma empresa de assistência técnica em refrigeração e climatização. Este foi o **primeiro projeto real** do autor, criado para atender a uma necessidade de negócio de verdade: apresentar os serviços da empresa e facilitar o contato direto de clientes via WhatsApp.

## ✨ Funcionalidades

- 🎯 Seção *hero* de destaque com chamada para orçamento
- 💬 Botão de contato direto via **WhatsApp**
- 🧊 Seção com a lista completa de serviços oferecidos
- ✨ Animações suaves ao rolar a página, usando a biblioteca **AOS (Animate On Scroll)**
- 📱 Menu responsivo com botão *hamburger* para dispositivos móveis
- 🦶 Rodapé com informações de contato e localização

## 🛠️ Serviços apresentados no site

- ❄️ Instalação e manutenção de ar-condicionado
- 🧊 Instalação e manutenção de câmara fria
- 🥶 Manutenção de freezer e geladeiras
- 💧 Manutenção de bebedouros
- 🏪 Manutenção de ilhas frigoríficas e balcões frios
- 🎨 Envelopamento em geral

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização e responsividade
- **JavaScript** — interações da interface (menu mobile, etc.)
- **[Font Awesome](https://fontawesome.com/)** — ícones
- **[AOS – Animate On Scroll](https://michalsnik.github.io/aos/)** — animações ao rolar a página
- **GitHub Pages** — hospedagem do site
